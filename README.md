# Big Data Policing: Racial, Ethnic and Socioeconomic Patterns in the Geography of Police Surveillance

Master's in Computational Social Science thesis that examines the relationship 
between local big data police surveillance and county-level demographic and 
socioeconomic predictors in the United States. Uses a weighted surveillance
index built from the Atlas of Surveillance dataset and a spatial econometric
(SARAR) model. 

## Repository Structure

```
thesis_github/
├── 00_setup.qmd              # Libraries, options, shared helper functions
├── 01_clean_atlas.qmd        # Clean Atlas of Surveillance data (dates, states, county matching)
├── 02_build_acs_ucr.qmd      # Build ACS demographic data + UCR crime/officer aggregates
├── 03_build_index.qmd        # Construct the weighted surveillance index
├── 04_validity_checks.qmd    # Validity checks on the index 
├── 05_eda.qmd                # Exploratory analysis, correlations, Moran's I
├── 06_models_main.qmd        # Main model sequence: OLS → SAR/SDM/SARAR → final model
├── 07_robustness.qmd         # Population threshold, all-agencies, and KNN robustness checks
├── 08_figures_tables.qmd     # Final tables and figures used in the write-up
├── correction-files/         # Manual corrections applied during data cleaning (dates, counties)
├── data/                     # Source data (Atlas of Surveillance, ACS, UCR/LEOKA)
└── figures/                  # Output figures and tables generated by the scripts
```
